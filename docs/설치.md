# 설치와 첫 실행

실행 대상은 macOS 또는 Linux의 제작 작업 공간이다. Windows 직접 실행은 검증하지 않았다. 일반 웹 채팅만으로 로컬 실행기를 구동할 수 없으며, 파일과 도구를 실행할 수 있는 에이전트 환경이 필요하다.

## 기본 검사

Python 3.10 이상을 준비한다. 핵심 계획 검사와 테스트는 표준 라이브러리를 사용한다. 압축을 풀고 이 폴더에서 실행한다.

```sh
python3 scripts/bootstrap.py --check
python3 -m unittest discover -s tests
```

`--check`는 설치나 계정 연결을 하지 않는다. FFmpeg·Node·Blender 등이 없으면 필요한 작업과 함께 미설치 상태를 표시한다. 기본 검사가 통과해도 미디어 제작 도구가 모두 설치됐다는 뜻은 아니다.

## 필요한 도구 준비

- FFmpeg와 ffprobe: 영상·음성 편집에 필요하다. 한국어 자막은 libass와 한국어 폰트가 있는 빌드를 사용한다. 직접 설치한 실행 파일은 SPORTS_FFMPEG_BIN과 SPORTS_FFPROBE_BIN으로 지정할 수 있다.
- HyperFrames: Node.js 22 이상과 pnpm 11.25.0을 준비한다. `python3 scripts/bootstrap.py --install-preview`를 명시적으로 실행하면 고정된 잠금 파일로 미리보기 의존성을 설치한다. 네트워크 다운로드가 발생하며 AI 생성은 하지 않는다.
- Blender: 3D 블로킹이 필요할 때 선택 설치한다. 마네킹 예시는 전문가 승인 동작이 아니다.
- Codex / Claude Code: 프로젝트 폴더를 열고 공통 운영 안내를 읽는다. 역할 정의는 포함되어 있다. ZIP에서 상대 링크가 유지되지 않으면 `python3 scripts/setup_studio_agents.py --refresh`로 재구성한다. 호스트 버전·권한에 따라 실제 하위 에이전트 호출을 별도로 확인한다.

자체 실행 환경에는 도구·폰트·저장 공간을 준비해야 한다. 이 배포는 브라우저 서비스나 컨테이너 설치 이미지가 아니다. 클라우드 작업자는 설계 단계다.

## 미리보기 구성

처음에는 활성 미리보기가 비어 있다. 에이전트에 “이 자료로 새 미리보기를 구성해 줘”라고 요청하고 기존 영상·사진·사용 가능한 폰트를 제공한다. 한 주기 참고 보드 빌더는 단일 동작 영상과 두 기준 이미지가 있는 경우의 제한된 템플릿이다. 범용 쇼츠 자동 편집기로 간주하지 않는다.

해당 빌더를 사용할 때 계획의 자산 ID는 `instructor-front`, `instructor-ready`, `motion-reference`이며 각 파일의 상대 경로와 SHA-256을 연결한다. 폰트는 사용권을 확인한 한국어 폰트를 `assets/fonts/korean-bold.otf`에 준비한다. 임의의 장면·영상은 HyperFrames composition 지침에 따라 별도 구성한다. 원본 파일과 폰트는 공개 배포에 포함하지 않는다.

## 계정과 회사 자료

외부 모델을 실제 호출할 때만 필요한 공급자 계정 키를 환경 변수에 등록한다. `.env.example`은 빈 참고 양식이며 자동으로 읽지 않는다. 키를 대화·기획·공개 Git에 붙이지 않는다. 계정이 있어도 현재 실행 범위와 견적 확인 전에는 유료 호출하지 않는다.

회사·강사·목소리·사용권 기준을 정하고 비공개 원본을 작업 공간에 준비한다. 현재 공개판에는 고객의 인물이나 생성 결과가 포함되지 않는다. 설치 직후에는 새 생성 권한이 없다.
