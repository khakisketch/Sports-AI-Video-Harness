# 실제 실행 사례 · 기존 영상으로 미리보기와 부분 수정

**확인일 · 2026.10.20**　|　**고객 자료를 사용하지 않은 공개용 시험**

## 무엇을 확인하려 했나요?

전문 역할이 편집 방향을 정하고, 기존 영상으로 미리보기를 만든 뒤, 원본을 새로 생성하지 않고 자막만 바꿀 수 있는지 확인했습니다. 이전에 Blender 도구로 만든 4초 무음 마네킹 영상을 사용했습니다. 실제 인물·회사 브랜드·개인 음성은 포함하지 않았습니다.

## 실제 작업과 결과

| 순서 | 실제로 한 일 | 확인할 증빙 |
|---|---|---|
| 1 | 공개 코드만 있는 별도 작업 공간에서 Codex 실행 | [실제 역할 실행 기록 화면](evidence/agent-terminal.png) |

| 8 | 별도 검토자가 실제 캡처 네 장을 열어 공개 적합성 확인 | 식별 정보와 신체 가림 확인, 로딩 표시 수정 후 재검토 |

역할 실행에는 프로젝트의 해당 역할 지침을 입력으로 전달한 네이티브 하위 실행을 사용했습니다. 설정 파일이 있다는 이유로 실행됐다고 기록한 것이 아닙니다. 실제 호출 원문과 하위 실행 기록을 대조했습니다. 두 역할은 이때 영상을 보지 않고 제공된 시간 조건으로 편집안을 작성했습니다. 화면 검토는 이후 실제 미리보기와 출력에서 수행했습니다.

## 어떤 수정이 가능했나요?

![실제 편집 전후 비교](evidence/output-comparison.png)

| 요소 | 첫 편집 | 수정 후 |
|---|---|---|
| 첫 자막 | 팔 내림에서 시작 | 시작 자세 확인 |
| 나머지 자막·표시 시간 | 첫 편집안 | 유지 |
| 동작 원본 | 기존 파일 사용 | 같은 파일 유지 |
| 편집 출력 | v1 별도 저장 | v2 별도 저장 |
| 새 AI 미디어 생성 | 없음 | 없음 |

원본 파일의 확인값을 대조해 변경되지 않았음을 확인했습니다. 자막 합성을 위한 영상 인코딩은 다시 수행했습니다. 원본 보존을 출력 파일 전체가 동일하다는 뜻으로 표현하지 않습니다.

## 실제로 어디까지 확인했나요?

| 확인 방법 | 확인한 것 | 확인하지 않은 것 |
|---|---|---|
| 역할 호출 기록 대조 | 실제 호출 2회와 역할별 반환 | 다른 호스트에서도 같은 품질로 작동한다는 보장 |
| 미리보기 자동 검사 | 구조·실행 오류 없음, 표본 레이아웃·대비 검사 통과 | 재미·연출·운동 정확성의 자동 승인 |
| 브라우저 재생·시간 표본 | 두 영상이 재생되어 4초 끝에 도달, 자막 상태 변화 | 사람의 연속 시청 판정이나 단어별 음성 정렬 |
| 출력 파일 검사 | 두 출력 모두 4초·270×480·12fps·48프레임, 전체 디코딩 성공 | 음성·립싱크 품질 |
| 실제 정지 화면 검토 | 한글 표시, 첫 문구 차이, 전신 프레이밍, 식별 정보 미노출 | 전체 동작의 정확성과 자연스러움 |
| 별도 검토자 재확인 | 비교 캡처의 로딩 표시 문제 해소, 공개 정지 화면으로 사용 가능 | 영상 연속 관찰·직접 청취·전문가 승인 |

세 영상은 모두 무음입니다. 저해상도 마네킹으로 확인한 도구 시험이며, 완성된 운동 강의나 전문가가 승인한 동작이라고 표시하지 않습니다. 새 유료 미디어 생성이나 클라우드 렌더링은 실행하지 않았습니다.

## 공개 자료는 어떻게 분리했나요?

고객 이름·회사 자료·실제 인물 이미지·작업 계정·이메일·개인 경로·세션 식별자를 제외했습니다. 역할 화면은 실제 실행에서 도구 이벤트와 최종 반환만 표시한 읽기 전용 터미널이며, 비공개 로그 전체나 숨겨진 추론 과정은 배포하지 않습니다. 미리보기 화면은 실제 Studio 캡처이고, 결과 비교 화면은 실제 MP4를 여는 브라우저입니다.

캡처를 그림으로 다시 만들거나 인물·자막을 사진 편집으로 덧씌우지 않았습니다. 비교 화면에서는 브라우저의 플레이어 조작부를 숨겼습니다. 공개한 영상에 자막이 실제로 합성돼 있는지는 MP4에서 확인할 수 있습니다.

시스템 폰트 파일과 비공개 작업 기록은 포함하지 않았습니다. 자막 원본을 다시 편집할 환경에는 사용 가능한 한국어 폰트가 필요합니다. 공개 캡처와 영상은 파일별 확인값을 등록하고, 등록되지 않았거나 변경된 바이너리는 공개 파일 검사에서 차단하도록 보강했습니다. 이 검사는 사람의 개인정보 확인을 대신하지 않습니다.
