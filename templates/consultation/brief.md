# 대화형 영상 제작 작업 기록

에이전트 작성용. 기획부터 제작·편집·검수·결과 정리까지 필요한 항목만 사용한다. 빈칸은 확정·승인이 아니다. 사용자에게 양식 작성을 요청하지 않는다. 기존 consultation.md 파일명도 계속 사용할 수 있다.

- 기록 버전·날짜:
- 사용자/작업자: 이번 대화에서 확인된 범위만 기록
- 별도 의뢰인/고객·확인 담당: 지정된 경우만 기록. 별도 담당이 없으면 임의로 만들지 않음
- 브랜드·시리즈·편: 미정
- 이번 요청과 발언 근거: 실제 발언 또는 접근 가능한 대화/파일 위치
- 이번 요청의 목표·완료 기준:
- 현재 단계: 아이디어 / 기획 / 자산 준비 / 미리보기 / 견적 / 생성 / 편집 / 검수 / 수정 / 결과 정리 중 해당 단계
- 현재 요청·기존 허용 범위와 근거:
- 이전 기록·작업 연결:

## 비교·선택한 기획

추천 요청일 때만 구별되는 후보를 작성한다. 이미 지정한 안은 그것을 구체화한다.

| 후보 | 시청자가 궁금해할 질문 | 첫 화면·핵심 전개 | 기존 자료 활용·부족한 근거 | 제작상의 불확실성 | 제안 이유 |
|---|---|---|---|---|---|

- 추천 방향과 이유:
- 사용자가 선택한 방향: 미정
- 선택 발언과 적용 범위: 미정
- 제외/수정한 방향과 이유:

## 제작 기록으로 연결

- 현재 plan.json / review-pack.md: 아직 없음
- 현재 reviews.json / quality-review.json: 아직 없음
- 현재 jobs.json 및 필요한 과거 작업 이력: 아직 없음
- 다음으로 준비하거나 검토할 결과:

장면·검토 점수·견적·승인 상태를 여기서 독립 관리하지 않는다. 실제 기록의 해당 버전에 연결한다. 허용된 작업은 실제 사용자 요청으로 판단하고, 이 양식 작성 자체는 어떤 실행의 승인도 아니다.
