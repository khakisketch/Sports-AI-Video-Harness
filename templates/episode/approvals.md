# 승인·변경 이력

아래는 빈 양식이다. 사용자 메시지나 검토 기록을 근거로 작성하고 승인을 추정하지 않는다.

## 승인 항목
- 승인 ID / 승인자 / 일시:
- 사용자 승인 문구 또는 해당 대화 위치:
- 종류: 내용 / 동작 / 강사·스타일 / 유료 실행 / 최종 납품
- 대상 파일·버전 / 장면 ID:
- 실행 도구·모델 / 아바타·음성·참조 자산:
- 생성 길이·해상도·수량:
- 견적 출처·조회 시각 / 서비스별 통화 또는 크레딧:
- 비용 미확인 항목과 그 상태에 대한 실행 승인 여부:
- 최대 비용 / 허용 유료 재시도 횟수:
- 유효 범위 / 무효화된 승인:
