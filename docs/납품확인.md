# 구축 결과 확인

이 배포의 납품 대상은 영상을 기획·제작·편집·확인할 수 있도록 구성한 작업 환경이다. 샘플 영상은 실제 활용을 확인하는 증거 중 하나이며, 시스템 구축 전체와 구분한다.

## 확인할 내용

| 항목 | 실제 확인 방법 | 남길 자료 |
|---|---|---|
| 설치 | 새 폴더에서 환경·자동 검사 실행 | 실행 일시, 버전, 결과 |
| 대화 사용 | 주제 요청→기획안→수정으로 이어서 진행 | 개인정보를 제외한 실제 대화·화면 |
| 역할 협업 | 필요한 역할을 실제 호출 | 역할별 입력·작업·결과, 호출 기록 |
| 미리보기 | 화면과 소리를 실제 시간으로 재생 | 연속 재생 확인과 결함·수정 기록 |
| 외부 제작 | 승인한 범위로 실제 계정 호출 | 결과 원본, 실행 기록, 실제 청구 확인 |
| 부분 수정 | 한 장면 또는 자막만 수정 | 전후 비교, 보존된 원본 확인 |
| 복구 | 기록한 작업을 조회·결과 회수 | 복구 결과, 새 요청 없음 확인 |
| 결과 전달 | 결과·편집 원본·사용 설명 전달 | 전달 목록과 실제 인수 확인 |

실행하지 않은 항목은 ‘미확인’으로 남긴다. 자동 검사 통과, 인물의 시각적 일관성, 운동 정확성, 소리 직접 청취, 고객 인수는 각각 따로 확인한다. 담당자 이름과 서명은 실제 담당자가 작성한다.

## 전달 묶음

공개 저장소의 버전 태그·커밋과 내려받은 묶음의 체크섬으로 공통 시스템의 버전을 특정한다. 실제 회사 자산·작업 기록·완성 영상·고객 검수 및 서명 자료는 별도 비공개 묶음으로 전달한다. 공개 저장소 링크가 고객 인수를 대신하지 않는다.
