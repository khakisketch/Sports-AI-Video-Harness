# 시스템 구축 결과와 확인 범위

확인일: **2026년 10월 20일**　대상: **공개 시험판 0.1.0-preview.1**

## 확인한 것은 무엇인가요?

대화형 제작 환경을 구성하는 소프트웨어의 동작과 배포 파일을 확인했습니다. 같은 자동 검사 150개를 작업 폴더, 새로 복제한 폴더, ZIP을 새로 푼 폴더, GitHub의 Linux 환경에서 각각 통과했습니다. 같은 검사 시나리오를 환경별로 반복 확인했습니다.

| 확인 구분 | 실제로 확인한 범위 | 증명하지 않는 것 |
|---|---|---|
| 계획·실행 전 확인 | 필요한 입력, 현재 승인 범위, 중복 작업과 한도 처리 | 실제 사용자의 승인을 소프트웨어가 대신하는 것 |
| 장면·원본 관리 | 기준 버전, 원본 식별, 채택 조건, 수정 영향 관계 | 해당 운동의 정확성과 실제 인물 일관성 |
| 외부 작업 연결 | 모의 응답을 사용한 요청 변환·상태 기록·결과 회수 처리 | 실제 계정의 API 접근과 유료 생성 품질 |
| 음성·동작 시간 확인 | 제공된 발화·행동 시점의 대조 | 자동으로 단어를 인식하거나 직접 청취했다는 것 |
| 역할 설정 | 공통 역할과 각 에이전트 환경의 정의 파일의 일치 | 해당 환경에서 모든 역할이 실제 호출됐다는 것 |
| 공개 파일 점검 | 정해진 파일·패턴 규칙에서 발견 항목 없음 | 모든 종류의 개인정보와 비밀을 탐지한다는 것 |
| 배포 파일 | 업로드한 ZIP의 확인값과 로컬 파일 확인값 일치 | 고객 설치와 실제 인수 완료 |

## 누구나 확인할 수 있는 근거

- [공개판 GitHub 자동 검사 원문](https://github.com/khakisketch/Sports-AI-Video-Harness/actions/runs/39357010015): Linux 환경의 150개 검사, 역할 설정, 공개 파일 점검.
- [공개 시험판·ZIP·SHA-256](https://github.com/khakisketch/Sports-AI-Video-Harness/releases/tag/v0.1.0-preview.1): 같은 버전의 배포 파일과 확인값.
- [검사 시나리오](../tests/): 계획, 장면 관리, 복구, 시간 정보 등 확인한 동작의 원본.
- [사용·운영 안내](사용안내.md): 사용자 요청을 실제 제작과 수정으로 이어가는 운영 기준.

작업 폴더·새 복제·ZIP 해제 검사는 제작자의 로컬 확인 기록을 근거로 정리했습니다. 해당 원문 전체에는 작업 환경 정보가 있어 공개 묶음에 포함하지 않았습니다. 공개 GitHub 기록은 위 링크에서 직접 열람할 수 있습니다.

## README 도식과 이미지의 성격

구축 목적과 시스템 구조 이미지는 제공된 역할·실행 도구·운영 기준을 요약해 직접 그린 도식입니다. 검증 결과 이미지는 위 실제 기록을 바탕으로 구성한 요약이며, 실행 화면을 촬영한 스크린샷이 아닙니다. 사용 흐름의 대화는 이해를 돕기 위한 요청 예시입니다.

## 실제 에이전트·편집 실행 증빙

설정 검사와 별도로 **공개용 마네킹 원본으로 역할 호출, 미리보기, 자막 합성, 첫 자막 부분 수정**을 실행했습니다. [실행 사례와 실제 캡처](실행사례.md)에서 과정과 MP4를 직접 확인할 수 있습니다.

README의 터미널·Studio·출력 비교 PNG는 실제 실행 화면을 캡처한 것입니다. 위 설명용 SVG 도식과 구분합니다. 역할 화면은 실제 이벤트의 읽기 전용 표시이며 Codex 데스크톱 화면은 아닙니다. 역할 호출 원문과 하위 실행 기록은 제작자가 대조했고, 별도 검토자는 실제 정지 캡처의 공개 적합성을 확인했습니다. 새 AI 미디어 생성은 하지 않았습니다.

공개 캡처 허용은 파일별 사람의 확인과 동일성 검사를 전제로 제한했습니다. 이를 확인하는 자동 검사 4개를 추가했습니다. 초기 배포본의 150개 검사 결과와 현재 코드의 검사 수는 구분하며, 최신 결과는 [현재 자동 검사 기록](https://github.com/khakisketch/Sports-AI-Video-Harness/actions/workflows/ci.yml)에서 확인할 수 있습니다.

## 실제 납품에서 추가로 확인할 것

회사의 실행 환경에서 도구·폰트·계정 연결을 확인하고, 실제 콘텐츠 한 편의 제작·수정·회수·전달을 검증해야 합니다. 인물 일관성, 실제 음성과 자막, 동작 정확성은 실제 결과로 확인하며 운동 전문가와 인수 담당자의 판단을 각각 남깁니다. [납품 확인 양식](납품확인.md)을 사용할 수 있습니다.
