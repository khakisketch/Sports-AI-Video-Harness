# Sports-AI-Video-Harness

**대화로 기획하고, 필요한 장면만 생성하고, 편집·검수·수정 기록까지 남기는 스포츠 영상 제작 작업 공간입니다.** Codex 또는 Claude Code처럼 프로젝트 파일과 도구를 다룰 수 있는 에이전트 환경에서 사용합니다. 일반 웹 채팅에 폴더만 첨부해 자동 제작하는 서비스는 아닙니다.

현재 버전은 **0.1.0-preview.1**입니다. 설치 준비와 오프라인 동작을 확인하는 공개 시험판이며, 실제 유료 API의 제작 품질이나 운동 전문가 승인을 보증하지 않습니다.

```text
사용자의 요청·수정
      ↓
AI 제작 감독 ── 조사·대본 / 시각 연출
      ↓
대본·장면 흐름 → 기존 자료·3D 미리보기 → 확인
      ↓
필요한 컷만 외부 모델 API로 제작
      ↓
컷별 확인 → 자막·도식·음량·장면 편집
      ↓
독립 검토 → 필요한 부분 수정 → 결과와 기록 전달
```

## 바로 시작하기

1. 이 저장소를 내려받아 압축을 풀거나 복제합니다.
2. Codex 또는 Claude Code에서 이 폴더를 엽니다. 설치 담당자는 [설치 안내](docs/설치.md)를 먼저 확인합니다.
3. 다음처럼 요청합니다.

> 우리 센터의 초보자용 운동 쇼츠를 기획해 줘. 먼저 주제 두 가지와 화면 흐름을 제안하고, 기존 자료로 미리보기를 만들어 줘. 새 유료 생성은 하지 마.

> 이 장면은 유지하고, 자막만 더 짧고 잘 보이게 바꿔 줘. 운동의 첫 한 주기는 자르지 말아 줘.

AI가 현재 요청 단계에서 시작합니다. 회사·강사·목소리·브랜드 기준은 새 사용자가 정하며, 이전 고객의 인물이나 실행 승인은 들어 있지 않습니다.

## 포함된 기능과 현재 범위

| 구성 | 제공 범위 |
|---|---|
| 전문 역할 | 제작 감독, 조사·대본, 시각 연출, 독립 검토의 역할 정의와 호스트용 설정 |
| 제작 지식 | 재배포 조건을 확인한 외부·프로젝트 스킬 24개. 원저작권 고지 포함 |
| 제작 관리 | 계획·검토·승인 범위·작업 중복 확인, 컷별 채택, 부분 수정 영향 추적 |
| 외부 생성 | LTX 영상 및 OpenAI 문자 과금 음성의 실행 연결 코드. 실제 계정·유료 실행 검증은 별도 |
| 로컬 편집 | FFmpeg 기반 트림·화면 맞춤·자막·음량 처리와 HyperFrames 미리보기 연결 |
| 동작 검토 | 선택적인 Blender 마네킹 프리비주얼. 전문가가 승인한 정확한 운동 원본은 별도 준비 |
| 복구 | 기록된 작업 조회·결과 회수. 새 유료 요청을 자동 재제출하지 않음 |

이미지·립싱크·보이스 복제는 공통 작업 종류만 정의되어 있습니다. Wan·fal.ai·Replicate·RunPod는 아직 연결된 공급자가 아닙니다. Higgsfield·HeyGen의 전문 기능은 호스트에 연결된 도구와 이용권을 확인한 뒤 선택할 수 있습니다. 클라우드 편집 작업자·고객 웹 서비스는 구현되지 않았습니다.

**로컬 영상 생성 GPU나 DGX 장비는 필요하지 않습니다.** AI 모델은 외부 API에서 실행하고, 이 작업 공간은 기획·실행 관리·편집·검수를 맡습니다. 에이전트 서비스·외부 API·유료 도구 비용은 별도입니다.
